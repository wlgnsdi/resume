인핸드플러스 · 복약관리 앱 Flutter 전환

배경

기존 Android 복약관리 앱을 운영하면서 iOS 사용자를 지원해야 했습니다. 소규모 팀에서 공통 기능을 두 플랫폼에 각각 구현하고 관리하는 부담을 줄이기 위해 Flutter 전환을 주도했습니다.

기술 선택과 설계

Flutter를 선택할 때 Android·iOS에서 공통 코드베이스를 사용할 수 있다는 점과 당시 커뮤니티 및 제작사의 지원을 고려했습니다. Provider와 Riverpod으로 화면 상태와 데이터 처리 구조를 구성했습니다.

구현

복약 기록 입력·수정·삭제, 서버 전송과 이력 조회를 구현했습니다. 이메일·QR 로그인, 캘린더와 Syncfusion 통계, FCM·로컬 알람을 활용한 복약 알림, Stream Chat API 기반 1:1 채팅도 개발했습니다.

결과

Android와 iOS 스토어에 앱을 출시했습니다. 출시 후에도 복약관리 앱 운영과 스마트워치 앱 유지보수를 병행했습니다.
