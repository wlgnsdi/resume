AI 기반 PDF 시험지 문제 변환

배경

PDF에 담긴 지문·문제·도표를 앱에서 바로 풀고 채점할 수 있는 학습 데이터로 바꾸는 서비스를 기획했습니다.

기술 선택과 설계

OpenAI와 Gemini 응답을 JSON으로 구조화해 문제를 추출했습니다. 도표와 이미지 영역은 좌표를 정규화하고 여백을 적용해, PDF마다 위치와 크기가 다른 도표도 잘라낼 수 있도록 구현했습니다.

구현

Supabase와 Google Cloud Run으로 백그라운드 작업을 처리하고 Realtime과 FCM으로 결과를 앱에 전달했습니다. Flutter·Riverpod으로 앱 상태를 관리하고 SQLite에 학습 데이터를 저장했습니다.

결과

PDF 변환부터 시험 타이머, 문제 풀이, 채점과 오답 학습까지 이어지는 흐름을 구현했습니다. 서비스 기획, 앱 개발, AI API 연동과 서버리스 백엔드 구현을 직접 맡았습니다.
