스푼라디오 · 실시간 채팅 성능 개선

배경

라이브 채팅에서는 메시지가 들어올 때마다 RecyclerView 목록을 갱신했습니다. 짧은 간격으로 메시지가 몰리면 화면 갱신이 반복돼 전체 메시지를 표시하는 데 시간이 걸렸습니다.

기술 선택과 설계

Android 클라이언트에서 수신한 메시지를 큐에 모아 일정 주기로 목록에 반영하도록 변경했습니다. 기존 사용자별 메시지 노출 정책을 유지하고, 목록 갱신 빈도와 채팅을 읽는 흐름을 함께 고려해 반영 간격을 검토했습니다.

구현

메시지가 들어오는 시점과 목록을 갱신하는 시점을 분리해, 한 번의 화면 갱신에서 그동안 수신한 메시지를 함께 반영했습니다.

결과

단일 기기 부하 테스트에서 메시지 표시 완료 시간이 약 10~20% 단축됐습니다. 개선 과정과 측정 결과를 SpoonLabs 기술 블로그에 공유했습니다.
